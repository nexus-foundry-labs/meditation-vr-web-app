# meditation-vr-web-app

Deployable static web app built with Nexus Vybe Cloud.

## Clarity Room

Clarity Room is a browser-based VR-style meditation prototype for a waiting-room demo. It includes a guided reset, calming ambient canvas motion, a vision-board visualization preview, and affirmation choices focused on calm, safety, and creative clarity.

## Run Locally

```bash
npm test
npm run preview
```

Then open `http://localhost:4173`.

The first iteration is fully static. API-backed image generation should be added through a server-side endpoint or trusted deployment function so credentials remain outside browser code.
