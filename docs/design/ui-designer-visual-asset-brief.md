# UI Designer Visual Asset Brief — Clarity Room

## Project
Meditation VR Web App — static browser prototype

## Purpose
This brief defines the image-generation assets needed for the first deployable Clarity Room demo. These assets should support a soothing, spacious, non-clinical meditation experience centered on creative clarity, calm, and safety.

---

## Overall Art Direction

The visual language should feel like entering a gentle inner room made of light, air, and soft natural forms. It should avoid hospital, clinic, or therapy-office cues. The app should look more like a calm creative sanctuary than a health product.

### Mood Keywords
- Spacious
- Soft
- Safe
- Warm
- Luminous
- Reflective
- Airy
- Gentle
- Imaginative

### Palette
Use a consistent palette across assets:
- Warm ivory
- Mist green
- Sage
- Pale sky blue
- Soft lavender
- Dawn peach
- Muted teal
- Gentle gold light

### Avoid
- Medical symbols
- Human faces
- Hospital rooms
- Overly spiritual iconography
- Religious symbols
- Dark psychedelic visuals
- High-contrast neon
- Text inside images
- Brand names or logos inside generated art

---

## Asset 1 — Hero Illustration

### File
`assets/hero.png`

### Intended Use
Arrival / hero section.

### Composition
A serene, softly lit room-like environment with a floating circular horizon, translucent panels, soft clouds or mist, and gentle arcs of light. The image should suggest an immersive browser VR space without showing a headset.

### UI Placement
Desktop:
- Right side of hero section in a rounded glass frame.

Mobile:
- Below headline and CTA, full-width within a rounded container.

### Aspect Ratio
16:10 preferred.

---

## Asset 2 — Vision Board Feature Illustration

### File
`assets/vision-board.png`

### Intended Use
Vision Board section.

### Composition
A calming abstract board of floating cards, color swatches, soft landscape fragments, leaves, light orbs, and horizon shapes. The artwork should imply creative visualization and intentional reflection.

### UI Placement
- Section visual near theme selector or selected-theme preview.

### Aspect Ratio
4:3 preferred.

---

## Asset 3 — Affirmation Orb Illustration

### File
`assets/affirmation-orb.png`

### Intended Use
Affirmations section.

### Composition
A luminous orb or softly glowing seed of light floating above a quiet surface, surrounded by subtle rings, mist, and small abstract petal shapes. It should feel supportive and steady.

### UI Placement
- Beside or behind the affirmation quote card.
- May be used as decorative background within the quote section.

### Aspect Ratio
1:1 preferred.

---

## Asset 4 — Brand Mark

### File
`assets/brand-mark.png`

### Intended Use
Header, footer, optional completion state.

### Composition
Simple abstract mark: a soft horizon line, small rising orb, and rounded enclosing shape. It should be readable at small sizes and not include text.

### UI Placement
- Header next to “Clarity Room.”
- Footer or completion card.

### Aspect Ratio
1:1 preferred.

---

## Implementation Notes

- All images should be optimized before production deployment if possible.
- Use CSS backgrounds and gradients as fallback if assets are unavailable.
- Do not rely on image text for accessibility or core meaning.
- Add meaningful `alt` text in implementation:
  - Hero: `Soft abstract room of light for a calming visualization experience.`
  - Vision board: `Floating abstract cards and colors representing a reflective vision board.`
  - Affirmation orb: `Soft glowing orb representing a steady affirmation.`
  - Brand mark: `Clarity Room abstract horizon mark.`
